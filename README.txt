PANDUAN UNDANGAN ELEKTRONIK IBADAH GMIT

ISI FOLDER
- index.html : halaman undangan interaktif
- musik.mp3  : tambahkan sendiri file musik/audio yang boleh digunakan

CARA MENJALANKAN DI WINDOWS
1. Ekstrak ZIP ke sebuah folder, misalnya Desktop/undangan-elektronik-gereja.
2. Buka folder tersebut di VS Code (File > Open Folder).
3. Buka index.html.
4. Cara termudah: klik kanan index.html > Open with browser, atau pasang ekstensi Live Server lalu klik Go Live.
5. Pastikan internet aktif untuk foto contoh, Google Maps, dan tautan WhatsApp.

YANG WAJIB DIUBAH SEBELUM DIBAGIKAN
1. Hari/tanggal, waktu, dan tempat acara pada bagian header.
2. Alamat acara serta pencarian peta Google Maps agar menunjuk lokasi yang benar.
3. Nomor WhatsApp contoh 6281234567890 di bagian akhir index.html.
4. Ganti gambar contoh dengan foto asli gereja/jemaat bila tersedia.
5. Tambahkan file audio bernama persis musik.mp3 ke folder yang sama dengan index.html.

CARA MEMBAGIKAN SECARA ONLINE
- Untuk uji coba lokal, halaman hanya bisa dibuka di komputer sendiri.
- Agar orang lain bisa membuka tautan, unggah folder/file ke layanan hosting statis seperti GitHub Pages atau Netlify.
- Musik lokal musik.mp3 harus ikut diunggah bersama index.html.
- Google Maps dan foto daring memerlukan koneksi internet.

CATATAN
- Tanggal dan jam sengaja dibuat sebagai teks yang perlu diisi, tidak dibuat-buat.
- Peta menggunakan pencarian nama jemaat; verifikasi pin dan alamat sebelum membagikan undangan.
- Autoplay musik mungkin diblokir browser. Pengunjung dapat menekan tombol play.
